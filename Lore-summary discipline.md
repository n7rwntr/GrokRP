Lore-Update Discipline (rules for future passes)

1. CARRY-ON CRITERIA — include only if it changes future scenes

Include:

    Dates, locations, named actors, named outcomes of decisions
    New standing roles, agendas, or dispositions
    Information access changes (who knows / who doesn't / who was read in)
    Lattice movements (with values)
    Schedules and deadlines that have not yet resolved
    Restricted-access markers [RESTRICTED: ...]

Exclude:

    Reasoning that produced the outcome (keep the outcome, drop the deliberation)
    Sub-step procedural mechanics already implicit in canon
    Scene-bound atmosphere, sensory beats, named extras
    Mid-scene calibrations between named characters
    Editorial framing ("on her terms," "intending to," "with the understanding that")
    Subordinate operational items unless they recur
    Anything one would only know by having been in the scene

2. ONE-OFF / FLAVOUR — leave in chat, exclude from lore

Tells, micro-gestures, period detail, scene atmosphere, the lame palfrey, Old Bess's autumn pears, the colour of the wine, dialogue cadence, Persimmon the cat, throwaway worldbuilding that won't load-bear later. These are the experience of the chat, not the state of the world. If a piece of detail is not going to be referenced again either in dialogue or in causal chain, it belongs in the chat record only.

3. CONDENSATION DISCIPLINE

    Past tense always. Lore is what has happened.
    Subject + verb + object, strip articles where unambiguous.
    Drop attributions when the actor is obvious from context. "Pycelle drafted documents" not "Master Pycelle was instructed to draft documents."
    Collapse multi-clause sentences unless each clause is independently load-bearing.
    Cut hedging and editorial language. "Wrath remained at full intensity" is editorial; the lattice values carry the load. "On her insistence" is framing; the action carries the load.
    One bullet per discrete state-change. If a bullet contains both a decision and a procedural detail, the procedural detail goes.
    Use canonical names without epithets. "Daenerys" not "the silver-haired Targaryen claimant."
    Reference, don't restate. If something is already in canon ("Suzaku's vermilion-flycatcher form"), don't re-establish it in updates.
    No conversational glue. No "after which," "leading to," "in the meantime." Date headers and bullet order carry chronology.

4. PRACTICAL FORMAT

For events: 1–3 bullets max per scene update. If a scene needs four bullets to summarise, the summary is leaking flavour.

For character updates: only the fields that have actually changed. Don't re-list unchanged Long-term agenda or unchanged Physicality. If only the Short-term goal and one lattice value have shifted, only those go in the update.

For minor characters (Moqorro, Mossador): 3-bullet maximum + lattice toward one or two key parties. Skip Physicality and Backstory unless POV is planned.

For new POV-eligible characters (Naerya): full sheet, but keep each field to one or two sentences max. The full character file is for orientation, not depth.

5. DIAGNOSTIC QUESTIONS BEFORE INCLUSION

    Will a separate, brand-new chat session three months from now need this fact to render the next scene correctly? If no → cut.
    Does this bullet describe a state of the world or a moment in a scene? If moment → cut.
    Could I remove this sentence and still reconstruct the consequences? If yes → cut.
    Is this the outcome, or the reasoning that produced it? Keep outcome. Cut reasoning.
